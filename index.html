A deliberate workflow

Built around the way an airtime desk actually works.

01

Know who every payment belongs to.

Keep Till and Number clients separate, store the right execution destination, and use an optional two- or three-way percentage split that always adds up to 100%.

02

See the whole transaction.

Each execution has its own durable run record, so completed airtime is never sent again during a retry.

03

Keep automation intentional.

Automation requires a deliberate hold to change state. When it is off, new work stays held until you choose to retry it.

04

Work with the phone, not around it.

AirLink runs the execution queue natively on the Android device, uses your selected SIM and USSD settings, and shows the active transaction from the persistent automation notification.

A safer working rhythm

Automation should be visible, recoverable, and under your control.

Duplicate guard
An M-PESA receipt is claimed once before it can change a client or create an execution plan.
Requirement holds
If Accessibility or units are unavailable, affected transactions remain held until you decide to queue them again.
Private client backup
Export client profiles into a protected AirLink file that keeps transaction history and sensitive settings out.
Clear recovery
Retries preserve completed airtime and only work on the unfinished execution legs.
